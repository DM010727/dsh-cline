# DSH Cline RSI 模式使用指南

适用版本：DSH Cline 4.5.1 的 RSI 试验功能。RSI 实现暂未开源，公开源码构建不包含该功能。

**一个管理中心查看全部项目；每个项目的开关、配置和经验分别保存。** 同项目的会话共用经验。你在管理中心查看项目 B，不会让项目 A 的对话使用 B 的经验。

第一次用，先开启当前项目，保持每日额外复盘 **0 次**，用 `/rsi-remember 回答请用中文，先说明改动，再说明验证` 保存一条习惯即可。

## 1. 先分清“次”和 token

RSI 有两种学习方式：明确记录你说的话，或者额外请求模型总结经验。只有后一种消耗额外复盘次数。

| 操作 | 额外复盘次数 | 模型边界 |
|---|---|---|
| `/rsi-remember`、经验新增/编辑/停用/删除 | 不消耗 | 本地处理 |
| `/rsi-list`、`/rsi-show`、`/rsi-status`、打开管理中心 | 不消耗 | 本地查询 |
| 聊天说“记住……” | 记录本身不消耗 | 正常聊天回复仍使用聊天模型 |
| 后续任务使用已有经验 | 不单独发复盘请求 | 经验会增加正常请求的上下文 |
| `/rsi-learn`、手动复盘、自动复盘 | 预留后消耗一次 | 请求配置的复盘模型 |
| 适用性反馈、“验证并尝试改进” | 不消耗 | 当前评测在本地执行 |

**每日额外复盘 3 次，指每天最多预留 3 次额外模型请求。不是 3 个 token、3 条经验或 3 元钱。** 0 次时，明确记录、经验管理和召回仍可使用。

RSI 不再单独设置单次输入字符或输出 token 上限；学习记录展示模型实际返回的输入/输出/总 token。未上报就是“未知”，不会估算费用。已取消或失败的预留也计次，避免自动重试超限；次数不等于供应商账单。每日按 UTC 更新，北京时间上午 8 点更新。

## 2. 开启项目，查看全部项目

每次打开 DSH Cline，会创建或复用与 VS Code 当前目录相同的 DSH 工作区并默认进入；已有同目录工作区不会重复创建。侧栏设置上方的 RSI 开关跟随**当前实际会话所属项目**，核对显示的项目名和路径后，点击即可按已保存配置开启。新项目默认每日额外复盘 **0 次**，无需先填写次数或再次确认。**开关影响这个项目的全部会话。** 手动切到另一项目的会话，开关随之切换；定位失败时不能操作，避免改到其他项目。

点击管理入口，或进入设置里的 **“RSI 项目管理”**，打开统一中心。左侧可以搜索全部本地项目，包括有历史经验但当前未打开的项目；右侧固定显示所选项目名称与路径，并分成三页：

- **经验**：搜索、筛选、新增、查看来源、编辑内容与条件、采纳候选、停用/恢复、删除、导出/导入。
- **学习记录**：查看实际召回、适用性反馈、复盘任务、所用模型、预留次数、真实 token 与修改记录。
- **项目配置**：设置该项目的能力开关、复盘模型、次数限制和自定义规范。

旧版本只保存路径散列，无法可靠找到路径时显示 **“待识别项目”**。原数据保留，不会猜测归属；打开原项目或在 DSH 原生工作区登记原路径后可识别。

## 3. 对话里随时记录或学习

输入 `/` 可以找到这些正式命令。它们操作的是**当前对话真实所属的项目**，不跟随管理中心选中的项目。

| 命令 | 用法 |
|---|---|
| `/rsi-remember <内容>` | 立即保存明确偏好，返回项目、内容、ID |
| `/rsi-learn [要求]` | 根据当前对话和任务证据提炼候选，可限定学习方向 |
| `/rsi-list [关键词]` | 查这个项目的经验 |
| `/rsi-show <ID>` | 查看内容、条件、来源与修改时间 |
| `/rsi-edit` | 在弹出的经验列表中选择一条，打开管理中心编辑 |
| `/rsi-edit <ID> <新内容>` | 直接更新这条经验正文，保留条件 |
| `/rsi-forget <ID>` | 删除这个项目的指定经验 |
| `/rsi-manage` | 打开全部项目管理中心，定位当前对话所属项目 |
| `/rsi-status` | 查看当前对话项目、开关、复盘模型与次数 |

`/rsi-edit <ID>` 不带新内容时显示原内容及编辑方法。ID 可以用没有歧义的前缀；有歧义会拒绝操作。

常用例子：

```text
/rsi-remember 解释改动时先说结果，再说如何验证
/rsi-remember --type=fact --when=依赖,构建 本项目使用 pnpm 管理依赖
/rsi-remember --type=procedure --when=发布,打包 发布前运行现有类型检查和构建
/rsi-learn 只总结这次构建失败和修复中可复用的经验
/rsi-list 构建
/rsi-status
```

也可以单独说“记住：……”“把这条记下来：……”“以后请……”“这个项目以后都……”“下次遇到这种情况……”。系统只从真实用户消息识别明确记录意图，忽略引文、代码块、模型和工具文本。没有把握时，用命令或管理中心明确保存。命中后会给出真实保存回执，不能只凭模型一句“记住了”判断成功。

主开关关闭时，明确的 `/rsi-remember` 仍可保存，回执会说明当前不召回；自动采集暂停。候选不会因为关闭再开启就被自动采纳。开启不修改已保存次数或模型；这些设置单独保存。

## 4. 经验怎么管理，怎样确认用上了

在管理中心选择项目，进入“经验”。修改旧经验直接点“编辑”，可改类型、正文和适用条件，不必先删再加。

| 类型 | 内容示例 | 条件 |
|---|---|---|
| 明确偏好 | 回答先说改动，再说验证 | 可留空，表示该项目通用偏好 |
| 项目知识 | 本项目使用 pnpm | 依赖、安装、构建 |
| 条件性经验 | 发布前先完成检查 | 发布、打包 |

项目知识和条件性经验至少填一个条件。多个条件用逗号或换行分开；当前按任务文字匹配关键词，不能写任意脚本或复杂表达式。

**已生效**表示具备被选用的资格，不是每次都会用。到“学习记录”查看“最近实际召回”，才知道具体任务带入了哪些经验。经验适合那次任务就点“适用”，不合适就点“不适用”。这评价的是经验是否适用，不是整个回答好不好。

停用保留内容但不再新召回；恢复可重新使用；删除移除这条经验及关联本地适用性记录。它们都不会撤回已经发给模型的上下文。

**经验 JSON 导出**用于备份经验正文、类型和条件。导入只写入当前明确选中的目标项目，重新生成 ID 与来源；不会合并聊天或复制运行状态。**配置 YAML**只保存配置，不包含经验。跨项目迁移必须手动选择目标并导入，不会自动共享。

## 5. 让模型总结：先选模型，再给次数

在所选项目的“项目配置”中，直接可见的“复盘模型与调用限制”区域选择模型与次数；无需展开自定义 RSI。需要模型总结时，再开启“任务复盘”：

- **跟随任务模型**：使用那次任务实际使用并保存的供应商/模型。之后在同一会话切换模型，不会改掉旧任务的模型。
- **指定模型**：从原生“模型”页已配置的供应商和模型中选择，可以跟聊天模型不同。凭据仍在原生模型页配置，RSI 不另收一套 API Key。

模型不可用或旧任务没有可靠的模型信息时，会明确说明原因，不偷偷换供应商。对旧任务，可选择已配置的固定模型后重新发起对话学习。

单次输入字符和输出 token 两项限制已移除，不用再填写。复盘使用已保存的任务证据，可接受的上下文与生成长度由所选模型及其原生配置决定；旧项目里保存的这两项值不再生效。每日额外复盘次数仍单独设置。

初次建议：每日额外复盘设为 **1 次**，触发选“仅手动复盘”，保存后在对话输入 `/rsi-learn`。它只读取有界的真实对话、助手输出、任务状态及获准工具结果，不会把整库和全部历史一次发送出去。

你开始新的正常任务时，前台优先，后台复盘会取消。前台仍在运行时发出的学习请求可以排队，回执会说明状态，不能把“已排队”当“已完成”。

生成的经验在“经验”页显示为候选。你检查内容和条件后再“采纳”；不准确就删掉。模型生成的候选，无论部署配置如何，都不会自动变成生效经验。

熟悉后，可把触发改为“任务结束且空闲时”。完成或失败任务可自动产生候选；用户纠正的内容也可成为真实证据。只有满足开关、证据授权与预算才会请求模型，不能因为说了“自动”就无限调用。

学习记录显示每次的触发方式、来源会话、实际模型、开始/结束状态、候选数与用量。零候选可能是正常结果；失败、取消和未执行都有原因。保留记录中的已上报 token 汇总不是无限历史账本，也不等于金额。

## 6. 自定义与验证的实际边界

日常只需管理经验，不必经常操作策略评分。六项能力分别控制偏好学习、项目知识、任务复盘、经验召回、工作流经验和学习器改进；修改后保存配置。

自定义 RSI 可以设置目标、候选生成指令、允许证据、模型、触发时机、模块和限制，支持有界声明式 YAML/JSON，详见 RSI Spec v1（在扩展中导入、导出）。当前不支持任意执行脚本、自定义代码评估器或训练模型权重。

本地评测只验证**经验召回的适用性**。证据不足就继续正常使用并留下真实反馈；不会把工具成功或模型自评当成你认可。修改经验、采纳/停用、修改反馈或项目事实变化，会使旧的待发布评测失效，需重新评测。

手动发布改变经验的挑选策略；历史配对回滚只改变挑选方式，不恢复已删除经验或项目代码。关闭项目 RSI 保留记录；清空会删除所选项目的学习数据并关闭它，其他项目不受影响。

记录保存本机，但被召回的经验和用于复盘的必要上下文会发给所选模型。不要把密码、密钥等保存为经验。
